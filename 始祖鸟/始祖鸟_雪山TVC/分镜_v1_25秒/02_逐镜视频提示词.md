# 雪山 TVC｜逐镜视频提示词（25 秒 v1）

使用方式：每镜单独图生视频；主图选 `关键帧/SH###_*.png`，同时附 `人物定妆/人物装备定妆_冰镐背包冰爪_v1.png` 与对应场景空镜作为一致性参考。所有视频 16:9、冷灰阴天、写实克制；保持人物从画面左下往右上攀登、三峰位于右上、风将头发吹向左。不添加新人物、装备、文字或标志。每镜头尾留约 0.5 秒剪辑余量。

| 镜号 | 时长 | 单镜视频提示词 |
| --- | --- | --- |
| SH001 | 1.5 秒 | 雪面低机位固定。黑色登山靴的一只冰爪从画面上方落入压实积雪，前齿咬住雪，几粒雪屑向侧面散开；动作只发生一次。结尾定在冰爪受力的瞬间，保留清脆压雪声。 |
| SH002 | 1.5 秒 | 黑色手套从右下伸向左侧暗岩，手指包住岩点并收紧，青蓝色衣袖受力产生细小褶皱。镜头只轻推一点；结尾手向画面右上发力，带出下一镜的攀登方向。 |
| SH003 | 3 秒 | 同一人物在斜坡左下方向右上连续攀登两步，冰爪稳稳踩雪，银灰直柄冰镐辅助支撑，黑灰小背包随动作轻晃。镜头缓慢后拉显露三峰与左侧云海；结尾人物抬头看山顶。 |
| SH004 | 2.5 秒 | 肩以上近景，人物刚停下，胸口轻起伏，吸气后呼出一小口白气，目光从前方慢慢抬向右上山峰。镜头极轻推近；保持相同五官、青蓝色衣领与向左吹的发丝。 |
| SH005 | 2 秒 | 严格右向侧脸近景，人物看着画面右侧的三峰，短暂停顿后把视线向下收至衣领。镜头固定，发丝向左轻动；结尾先听见手套摩擦冲锋衣的声音。 |
| SH006 | 3.5 秒 | 腰上中近景，人物低头，黑手套握住青蓝色冲锋衣腰部的中央拉链滑块，缓慢而连续地往上拉至胸口。镜头只沿滑块轻微上移。拉链初始敞开，经过处逐渐闭合；保持同一只手与准确的衣片连接。 |
| SH007 | 2 秒 | 拉链与下半张脸极近景，延续上一镜：同一只手从胸口将滑块拉到领口下方，滑块轻碰顶端后停住。镜头随滑块向上，最后留下画面中央清楚的竖直拉链线与短促“咔哒”声。 |
| SH008 | 3 秒 | 切到无人雪山脊线。脊线从画面下方中心向三峰上行，镜头沿雪与暗岩交界线低速前进，云雾在左侧缓慢流动。开头脊线与上一镜拉链线位置、方向相接；只有风声。 |
| SH009 | 3 秒 | 同一座山更远的无人山脊，镜头缓慢后拉，山脊与云海的尺度逐步展开，三峰稳定在右上。结尾让一块近处岩石短暂扫过画面作为下一镜遮挡剪辑点。 |
| SH010 | 3 秒 | 遮挡后显现同一山脊极远景，青蓝色小人物稳定站在脊线上，面向右上方三峰，只有衣角和发丝受风轻动。镜头近乎不动，停留在“人与山”的比例上，最后留出静止余量供后期收尾。 |

**镜头衔接**：SH001→002 用雪粒与岩屑质感切；002→003 用手向右上发力切；003→004 用抬头视线切；004→005 用向右的视线与风声切；005→006 用低头视线和提前进入的布料声切；006→007 保持拉链同一上行动作；007→008 拉链线匹配山脊线并保留“咔哒”声尾；008→009 延续脊线前进方向；009→010 用前景岩石遮挡切。
