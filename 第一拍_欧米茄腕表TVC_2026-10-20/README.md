# 《第一拍》｜30 秒腕表 TVC 概念

一位女性指挥家走向舞台。观众与乐团屏息等待；她落下第一拍，音乐在六秒连续镜头中展开。腕表以欧米茄 De Ville 系列的正装气质为概念方向。

## 当前版本

- 时长：30 秒；画幅：16:9；目标帧率：24 fps。
- 女主角：以 [`参考图/01_女主角定妆.png`](参考图/01_女主角定妆.png) 为外貌基准，保持长发与黑色指挥服。
- 腕表：以 [`参考图/02_腕表定稿_银色精钢表链.png`](参考图/02_腕表定稿_银色精钢表链.png) 为外观基准。最终选择银色精钢表链，不使用皮表带或银金双色版。
- 左右手：女主**左腕戴表、右手持指挥棒**，参见 [`参考图/03_左腕戴表右手持棒.png`](参考图/03_左腕戴表右手持棒.png)。
