# 迈巴赫 TVC《驶出尼伯龙根》

本仓库保存概念广告的分镜、生成素材、试剪视频与制作记录。当前可观看的完整试剪是 `迈巴赫TVC_顺接重剪_v11_对视擦身去重复_30fps_2026-10-19.mp4`；它是诊断版，尚未完成全片连续性与声音制作。

## 从哪里开始

- `全片重构诊断_2026-10-19.md`：当前全片问题与下一步制作顺序。
- `迈巴赫TVC_制作进度与明日接续_2026-10-18.md`：较早的制作背景与素材说明；其中“v8 为最新版本”的描述已被 v9–v11 试剪更新。
- `生成好的素材/`：人物、车辆、场景、分镜关键帧与视频素材。
- `补分镜_奥丁投枪_2026-10-16/`：第一次投枪桥段补镜资料。
- `第二次投枪_避让重做_2026-10-19/`：第二次投枪的尝试与诊断素材。目录内的旧提示词不应直接用于继续生成；先按全片重构诊断确认动作与空间。

## 下载素材

MP4、PNG、JPG 使用 Git LFS。克隆前安装 Git LFS；克隆后运行 `git lfs pull` 获取完整媒体。没有 Git LFS 时，工作区中可能只有媒体指针文件。
