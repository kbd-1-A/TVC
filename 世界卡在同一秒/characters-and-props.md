# 《世界卡在同一秒》｜角色与道具设定

本清单按约 38 秒故事整理，用于后续选角、产品定妆、场景资产与分镜。产品为原创概念水果气泡饮；主角已更换为用户新提供的照片人物，现有新版全身参考图及三视图。

**主角参考图**：[新人物面部与发型参考](./references/主角/protagonist-face-reference.png)；[新主角全身参考图 v1](./references/主角/protagonist-fullbody-new-v1.png)；[正面／侧面／背面三视图 v1](./references/主角/protagonist-turnaround-new-v1.png)；[正面 45° v1](./references/主角/protagonist-front-45-new-v1.png)；[背面 45° v1](./references/主角/protagonist-rear-45-new-v1.png)；[四格面部表情近景 v1](./references/主角/protagonist-expressions-new-v1.png)。人物参考照用于锁定面部、棕色长卷发与大耳环；全身图与各视角图统一白色短上衣、黄色宽松裤和腰间格纹衬衫。表情图从左上到右下依次为麻木、察觉与好奇、惊讶、笑出声。

**店员参考图**：[灰银短发咖啡馆全身图](./references/店员/clerk-ash-gray-cafe-v1.png)；[正面／侧面／背面三视图](./references/店员/clerk-ash-gray-turnaround-v1.png)；[克制表情近景](./references/店员/clerk-closeup-subtle-v1.png)。以用户选定的咖啡馆全身图为人物基准；参考图只借用灰银色蓬松短发，不借用其服装或画面文字。近景表演以短暂停顿和细微眼神变化为主。

## 角色

| 角色 | 出镜任务 | 固定造型与表演 | 资产优先级 |
|---|---|---|---|
| 主角 | 发现循环、开罐、追纸鸟、带产品走出店外 | 以新参考照中的女性为面部基准：棕色长卷发、大号银色圈形耳环；白色贴身短款半袖上衣，明亮黄色的全长宽松阔腿裤，黄棕格纹衬衫随意系在腰间；米沙色复古运动鞋为全身图中的暂定搭配。前段眼神疲倦、动作受节拍限制；后段好奇、主动，但不夸张表演。 | 高：新版全身参考图和三视图 v1 已生成。 |
| 店员 | 固定放杯子，之后应对弹跳的杯子与拐弯的咖啡 | 约 22 岁的青年男性，蓬松灰银色短发，略带痞帅但动作专业利落。深咖色短袖翻领工作衫、细奶油色滚边、深咖色半身围裙、盖住脚踝的深色全长直筒裤和黑色厚底皮鞋。面对异常短暂困惑后继续一本正经工作。 | 高：咖啡馆全身图与三视图已生成，以用户选定的全身图锁定面部。 |
| 骑车人 | 开场按同一路线经过；后段倒滑回来，影子继续向前 | 约 25–35 岁；深蓝短款防风外套、浅色头盔、深灰长裤、白色运动鞋。表情困惑只需一瞬。 | 中：如出现清楚面部，做角色三视图；若只保留中远景，可使用固定造型描述。 |
| 邻桌客人 | 提供飘落的纸，不承担独立笑点 | 仅露手部或肩背；深绿色针织上衣。 | 低：无需单独角色资产。 |

**人数控制**：有辨识度的角色为 3 人。其余顾客可作虚化背景，避免大量人物在重复镜头中产生走位误差。

## 核心产品

| 道具 | 第一版设计 | 剧情用途与一致性要求 |
|---|---|---|
| 水果气泡饮罐 | 330 ml 细长铝罐；哑光浅银底色，粉红葡萄柚色与青柠绿色的大块弧形色带；银色易拉环，罐身不依赖可读文字。 | 开场放在主角手边，罐身色彩与主角的黄色裤装形成呼应；开罐后被主角带着穿过各场景；结尾纸帽落在罐顶，再以无纸帽的完整产品做 End Frame。罐形、色带位置、拉环方向需全片一致。 |

**暂定口味**：粉红葡萄柚＋青柠。具体口味可以改，但进入产品多视图制作前需锁定配色与罐身图形。

## 表演道具与特效物件

| 道具 | 固定外观 | 用途 |
|---|---|---|
| 咖啡杯与杯碟 | 米白陶瓷小杯，深蓝细边；同款圆形杯碟。 | 开场三轮重复落桌；开罐后在杯碟里弹两下。杯子不可在镜头间换形。 |
| 咖啡壶与咖啡液 | 矮嘴不锈钢手冲壶，深棕咖啡液。 | 店员倒咖啡；液流在空中绕弯后入杯。保持倾倒方向一致。 |
| 飞纸／纸鸟 | 一张无印刷、暖白色 A5 纸。 | 开场反复飘落；开罐后折成小鸟，飞向店门，最后折成落在罐顶的小纸帽。纸鸟和纸帽必须由同一张纸变化而来。 |
| 小票 | 窄条暖白色热敏纸，避免可读文字。 | 被纸鸟叼走并在片尾归还；与 A5 飞纸是两件不同道具。 |
| 店门 | 木框玻璃门，圆形金属拉手。 | 主角推门时门先退后开；门的开合方向和店内外位置固定。 |
| 自行车 | 简洁的奶油白城市单车，黑色车轮。 | 三轮重复经过、后段倒滑；车轮与影子分离的视觉笑点。 |
| 水洼 | 店门外人行道上一处浅水洼。 | 现实街景仍偏克制，水中映出晴天与果树；是独立的倒影特效，不需要真实果树出现在街上。 |
| 气泡 | 少量透明气泡，边缘带粉红和青柠的微弱反光。 | 作为开罐后异常出现的视觉线索；避免每个道具都被气泡击中而显得公式化。 |

## 场景与布景

1. **街角咖啡店室内**：主角靠窗的小桌、邻桌、吧台和玻璃门要处在可理解的连续空间内。开场使用固定机位与重复走位；开罐后镜头从桌边跟随主角经过邻桌、吧台、店门。
2. **店外人行道**：玻璃橱窗、自行车经过的路线、门口水洼与街角保持同一地理关系。高潮不需要换到其他街区。
3. **产品定格空间**：干净背景，承接罐身的粉红与青柠色；产品完整可见，并为品牌标识与文字预留空白。

## 视觉资产制作顺序

1. 产品多视图：锁定正面、侧面、背面、开罐口与色带细节。
2. 新主角全身参考图、三视图、正面／背面 45° 视角图及四格表情图 v1 已生成。店员灰银短发咖啡馆全身图及对应三视图已生成。骑车人是否需要三视图，待分镜景别确定。
3. 咖啡店室内场景图与店外人行道场景图；两图统一门、橱窗和街景位置。
4. 纸鸟、杯子和自行车可作为道具参考纳入场景资产，不单独增加一类资产。
