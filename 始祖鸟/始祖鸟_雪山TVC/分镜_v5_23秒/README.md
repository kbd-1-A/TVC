# 雪山 TVC｜23 秒分镜 v5（当前版）

本版保留 SH001–SH006 的攀登动作，更新 SH007–SH008 的山脊衔接，并重做 SH009。SH007 已在山脊上放入远处人物；SH008 起帧与 SH007 是同一张图，后两帧沿同一条山脊逐步后拉。结尾的远景负责揭示人物走过的路线和山体尺度，最后一镜负责完成攀登动作。

### 生成视频时的动作约束

- SH004 的冷空气呼吸要在视频中短暂出现、稍微变明显后随风散去；不要把静帧里的白雾当作整段持续的形状。
- SH006 的拉链在前约 1 秒到顶，手离开后轻抬眼；`SH006_03_OUT.png` 仍低头，只用于衣领与拉链细节参考，不锁定视频尾帧。
- SH007 末帧与 SH008 起帧为完全同一图像；成片中 SH008 从此画面直接开始后拉，不能在这里让人物再次出现或切换山体。
- SH008 是**一个持续后拉的镜头**，三帧代表不同摄影机距离；山体三峰、山脊方向、人物所处的未登顶位置必须保持一致。禁止把三帧做成三个不同雪山的风光蒙太奇。
- SH008 OUT → SH009 START 是从极远景切回同一脊顶的后侧中远景。沿用同一座山、同一条攀登路线、同一青蓝色人物。
- SH009 的动作只完成**最后一步和站稳**；冰镐自然低垂，衣服随风鼓起，不摆造型，不夸张举手庆祝。
- 末帧可在人物停稳后保留约半秒呼吸空间，再结束。没有新增口号或品牌标志。

预览长 23 秒、24 fps，为静态关键帧节奏示意；真正的连续动作、风雪和后拉运镜仍需图生视频制作。此项目是始祖鸟风格概念练习，服装图不是经过核验的官方产品素材。
