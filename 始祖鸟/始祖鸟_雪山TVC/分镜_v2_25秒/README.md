# 雪山 TVC｜25 秒分镜 v2

这是针对 v1 十张单幅参考图的修订版。**十镜，每镜 START／KEY／OUT 三张，共 30 张连续关键帧**；另有逐镜三帧板、十镜总览和 25 秒无声节奏预览。它们用于确认动作、机位和剪辑衔接；视频预览由静帧定时拼接，尚非逐帧运动视频，也不等于已经生成完整 25 秒成片。

## 先看哪里

1. [十镜三帧总览](00_十镜三帧总览.png)：快速检查全片景别变化。
2. [25 秒节奏预览](25秒三帧节奏预览_无声.mp4)：按 25 秒时间线播放 30 张静帧，无声。
3. `逐镜三帧板/`：每个镜头的起点、关键动作、出镜图。
4. `30张连续关键帧/`：按 SH001–SH010、每镜 01–03 排列的干净单帧。
5. `原始三帧图/`：未拆分的原始生成图；`build_storyboard.py` 只负责裁开和排版，便于重建交付物。

## 时长及动作

| 镜头 | 时间 | START → KEY → OUT | 下一镜的接法 |
| --- | --- | --- | --- |
| SH001 冰爪 | 0–1.5s | 悬空 → 前齿入雪 → 完全承重 | 以压雪的短促声尾切到岩石近景；**不同机位**，不复用雪地底图。 |
| SH002 抓岩 | 1.5–3s | 手入画 → 触岩 → 握紧发力 | 黑手套向右上发力，顺方向切 SH003 人物上攀。 |
| SH003 攀登 | 3–6s | 坡下 → 上一步 → 抬头 | 目光抬向画面右侧，切 SH004 近脸。 |
| SH004 呼吸 | 6–8.5s | 低头 → 抬眼 → 呼白气 | 继续右向视线，切 SH005 侧脸。 |
| SH005 视线 | 8.5–10.5s | 望峰 → 转眼 → 看胸前 | 视线落点引到 SH006 拉链滑块。 |
| SH006 迎风调整 | 10.5–13s | 迎风停步 → 顺手找到拉头 → 拉至胸中 | 侧面中景同时看见脸、背包和雪山；动作由风触发，不把拉链当展示品。 |
| SH007 拉链到领口 | 13–14.5s | 胸中 → 快速拉合 → 到顶继续上看 | 仍是侧面人物中近景，滑块到顶声作为剪辑点；衣服的斜向线条接 SH008 脊线。 |
| SH008 近脊 | 14.5–18s | 低角度岩脊 → 前移 → 近岩深化 | 沿脊线前移，切到 SH009 高空后拉。 |
| SH009 山体 | 18–21.5s | 主峰较近 → 退远 → 山群全貌 | 极远景已交代山体位置，切 SH010 地面机位看见攀登者。 |
| SH010 人物 | 21.5–25s | 踏上脊线 → 站稳 → 望峰 | 停在人物和三峰，预留后期字卡空间。 |

## 连续性核对

- **001／002**：冰爪和岩点现在使用两套不同取景，靠环境音和向右上的动作方向连接；不是让同一背景突然换动作。
- **006／007**：两镜合计从 5.5 秒缩至 4 秒。风吹来时她顺手拉合衣领，侧面机位仍能看见攀登姿态与山景。整件外套只有一条主拉链和一个滑块；滑块以下已咬合，以上保持未拉合。SH006 到胸中，SH007 从胸中继续到领口。原 v1 的大开口、错位拉头不再作为成片依据。
- **008／009／010**：低角度雪岩纹理 → 高空山群尺度 → 地面视角人物，景别和机位明显不同。SH010 的青蓝色上衣在缩略图中仍能辨认。
- **人物和环境**：同一位深棕色中长发女性；青蓝色外套、黑色裤子与手套、黑色背包、冰爪；冷灰色天空，风向将头发吹向左；人物上行方向维持画面左下至右上。

## 后续视频制作时的重点

本版每镜三张是**动作节点**，不是 24 fps 的完整逐帧画面。若制作 25 秒 24 fps 视频，最终视频约有 600 帧，镜间运动、呼吸、雪粒、衣服和云雾需要再用视频生成／实拍／后期插值完成。逐镜视频应先使用各镜 START 与 OUT 约束首尾，KEY 指定中间动作，再检查生成视频中是否真的只有一个拉头、手指与冰爪结构是否稳定。`25秒三帧节奏预览_无声.mp4` 只用于看叙事节奏和接镜，不代表视频动作已经完成。

此项目是始祖鸟风格概念练习；图中装备与外套为 AI 概念素材，未经真实产品型号和官方商标核验。
