# 《地形裁片》30 秒概念样片

本目录为创意动态预演，不是品牌正式广告。画面中的冲锋衣是无标识占位外观，未对应始祖鸟具体型号。

## 文件

- `地形裁片_30秒概念样片_v2.mp4`：最终预演，30 秒，960×540，24 fps，带原创环境音。
- `images/`：使用内置图像生成工具制作的六张关键画面。
- `render_animatic.py`：运镜、剪辑、声音和片尾字卡的渲染脚本。

## 关键画面提示词要点

1. **地形**：灰色旷野的俯拍特写，一道斜向山脊线，清晨阴天，大面积留白，无人物。
2. **衣服裁片**：无标识深灰色技术冲锋衣肩部近景，清晰真实的斜向裁片线，与山脊线形成匹配剪辑。
3. **人物入野**：穿深灰色冲锋衣的人从远处走向山脊，人物很小，荒野辽阔，克制的编辑摄影。
4. **登上山脊**：人物站上山脊，背侧视角，静止而非英雄姿态。
5. **片尾产品**：穿着状态的冲锋衣三分之四背侧近景，右侧留白供片尾文字。
6. **山线衣线同框**：前景衣服肩线与背景山脊线同时入画，以摄影构图建立视觉呼应。

生成工具：内置 `image_gen`。视频由上述静帧加模拟镜头运动与原创合成音效剪成。实际产品制作前需以具体型号的真实参考图替换占位外观，并重新核对裁片、颜色与标识。
