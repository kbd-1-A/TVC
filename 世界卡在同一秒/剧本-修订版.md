> 基于 `story.md` 与 `references/新建文本文档.txt` 整合修改。此稿先锁定故事和动作因果，尚不是逐镜分镜表。

> 人物、产品、道具与场景统一采用中文标识；现有图片及待补项目见 [《人物与道具清单（55 秒版）》](./人物与道具清单-55秒版.md)。

## 故事定位

- **片长**：约 55 秒。
- **一句话故事**：困在重复一秒里的主角，打开一罐水果气泡饮，走到马路上；她目光所到之处，气泡接连落下，让护栏、汽车与高楼一件件变成意想不到的样子。
- **情绪线**：习惯重复 → 发现异常 → 主动选择 → 惊喜失控 → 享受当下。
- **视觉规则**：开罐前，现实空间以偏灰、米白、冷棕为主，同一秒的动作精确重演；饮料是画面里唯一鲜亮的颜色。开罐后，气泡触到哪里，哪里的颜色、动作或形态才发生改变；变化逐处扩散，最终让主角与其他人误闯进一座完整的原创动画城。人物、产品及关键道具的身份与位置保持连续，店内外环境采用统一的三维动画世界造型。
- **主角两套造型**：开罐前穿灰米色宽松短袖上衣、冷棕灰阔腿裤、灰棕格纹腰间衬衫；开罐后，气泡触碰服装并依次将其变为现有参考图中的白色短上衣、亮黄宽松裤、黄棕格纹腰间衬衫。这是画面中真实可见的服装变化，不只靠调色完成。人物面部、长卷发、大耳环和鞋子保持连续。

## 店内空间与行动路线｜已选 A：斜向推进

开罐前场景参考：[咖啡馆室内宽敞空间基准图 v2](./references/场景/咖啡馆室内-开罐前-宽敞空间基准-v2.png)。以加深加宽后的空间为准，锁定桌位、吧台、唯一的右前玻璃店门、橱窗与宽阔行动通道；旧版 v1 空间偏小，不再用于分镜。时钟及小票的具体位置在分镜阶段补定。

开罐后室内场景参考：[动画城室内 v4](./references/场景/咖啡馆室内-开罐后-动画城-v4.png)。墙面、吧台、家具和地面进入与[店外动画城街道 v4](./references/场景/咖啡馆外街角-开罐后-动画城街道-v4.png)一致的原创三维动画世界；左侧靠窗桌位、右侧吧台、右前店门及中央行动通道保持连续。气泡使用[透明单颗素材](./references/道具/气泡-透明单颗-v1.png)或视频生成单独控制轨迹。旧[蓝黄配色无泡泡底图 v3](./references/场景/咖啡馆室内-开罐后-无泡泡底图-v3.png)与[含静态泡泡 v2](./references/场景/咖啡馆室内-开罐后-蓝黄配色-v2.png)留作历史参考，不作新版视频底图。

店外街角参考：[咖啡馆外街角开罐前空间基准图 v1](./references/场景/咖啡馆外街角-开罐前-空间基准-v1.png)，用于锁定同一排黑框橱窗、右侧玻璃门与门前路沿。**店外主体镜头转向沿街向右前方的马路**：主角从门口走下路沿，进入宽阔的近侧车道并持续向右前方走；摄像机在她前方倒退或从侧后方跟拍，咖啡馆逐渐退到画面左后方。她不是停在门口观看。骑车人沿街从左向右经过，与主角保持横向距离。

店外变化沿主角行走路线逐级放大：路沿原有的黑色金属护栏变为木栅栏；右前方原有的灰色汽车变为驯鹿牵引的开放式雪橇；她抬头望向前方那座**开罐前已经存在的灰色玻璃高楼**，气泡沿楼体向下扩散，将它变成保留层数、窗格和占地的水果色动画城高楼；路旁原有的黑色街灯随后变为弧形果色灯。骑车人与自行车保持原造型，留给影子笑点。[沿马路前望的开罐前街道](./references/场景/马路前望-开罐前-预览-v1.png)已锁定汽车、高楼、街灯与道路方向；[开罐后街道](./references/场景/马路前望-开罐后-纯场景定稿-v2.png)仍画着旧版马车，仅作高楼、路面和色彩参考，正式分镜需改为驯鹿雪橇。门旁花盆只作背景，不占单独变形镜头。

**气泡视频规则**：开罐前画面无气泡；开罐后第一批从罐口向上升起，越过画面顶端后分流、轻轻回落，先触碰三处店内细节，再沿中央通道、窗边、店门继续运动。每颗气泡持续平移、轻微摆动和改变大小，触到物体时变化从接触点向外扩散，再弹开、破裂或飞出画面。不可让气泡在空间里原地悬停，也不可把含静态气泡的参考图直接当作视频底图。

以下方位以咖啡馆俯视平面为准：**上方是店内深处，下方是临街玻璃窗；画面左、右以从街上看向店内的建立镜头为准**。后续镜头可改变机位，但桌位、吧台、门的实际相对位置不变。

```text
                     店内深处
        ┌────────────────────────┐
        │ 邻桌／A5 纸      吧台／饮料 │
        │ 主角座位          右侧通道  │
        │                  店门      │
        └──────临街玻璃窗────────┘
                       街道
```

- **入场**：主角从右前方店门进入，沿桌椅前侧走向左侧靠窗座位，拉开椅子坐下；邻桌在她的左后方、靠店内深处。
- **走向产品**：主角从左侧座位起身，沿桌子与吧台之间的空通道，斜向右后方走到吧台。饮料固定摆在吧台朝向顾客的一侧，小票由店员推到饮料旁边。
- **出店**：主角拿着已开罐饮料，从吧台转向右前方，沿右侧通道跟着纸鹤走到同一扇店门；出门后走下路沿、进入马路，继续向右前方行走。不横穿邻桌，也不在镜头间换一扇门。
- **纸鹤路线**：邻桌 A5 纸落地成鹤 → 绕主角与饮料一圈 → 飞向吧台叼走小票 → 沿右侧通道飞出门 → 街道上折返。小票是被带走并归还的另一件道具。
- **街外方向**：主角沿马路向右前方走，镜头跟随她的肩膀和视线，依次看向路沿护栏、前方汽车、上方高楼与路边街灯；每次她看见旧物，下一颗气泡才落到该物上并开始变形。骑车人从左向右经过，在独立的骑行路线停下；影子仍沿原方向继续骑。

## 正式剧本

### 01｜同一秒，一直重来（0–12 秒）

清晨的街角咖啡馆。右前方的临街玻璃门被推开，主角穿着灰米短袖、冷棕灰阔腿裤和灰棕格纹腰间衬衫进入店内，走向左侧靠窗座位，拉开椅子坐下。邻桌在她的左后方，吧台在右后方。桌椅、咖啡机、杯碟都整齐得近乎刻板；整个空间是灰、米白与冷棕色。靠窗的客人端起咖啡，店员将一只米白色细蓝边杯子放上杯碟，窗外一位骑车人从左向右掠过。

“嗒”——杯子落桌。邻桌一张暖白色 A5 纸被风掀起一角。墙上秒针跳向下一格，却立刻回到原位。

主角学着客人端起咖啡。她刚要喝，**同样的一秒再次发生**：同一声“嗒”，同一张纸掀起同一个角，窗外同一辆车经过同一个位置。第三次，主角没有再举杯。她先看向杯子，再看向停在原处的秒针；她已经知道下一声“嗒”何时会响。

### 02｜唯一没有重复的颜色（12–20 秒）

主角听着下一声“嗒”将要响起，动作停了一下，视线自然地移向右后方吧台上的一罐水果气泡饮；她此时没有刻意微笑或惊讶。它始终在那里，只是之前被单调的节奏淹没；亮黄罐身与葡萄柚粉、青柠绿的果片图案，成为灰色画面中唯一鲜明的颜色。主角先一步站起，沿桌子之间的通道斜向右后方走到吧台。

她拿起饮料。店员把一张窄条小票推到罐子旁；主角顺手将小票压在吧台边，手指扣住拉环。客人仍照旧举杯。主角拉开罐口。

**“嘶——”** 清脆的开罐声盖过即将响起的“嗒”。秒针终于越过原来的刻度。店员与客人同时停下动作，看向主角手中的罐子。几颗带粉、绿、黄反光的透明气泡从罐口升起，向四周散开后开始回落。

### 03｜变化从一颗气泡开始（20–35 秒）

紧接开罐，给三个短促的同机位特写，让观众亲眼看见**开罐前的同一处景物被气泡碰到，逐步变成开罐后的样子**。第一镜：吧台边灰米色桌面仍是开罐前的冷调，气泡落下，触点晕出亮黄与柔和木色，桌面纹理沿原有边缘展开。第二镜：米白色细蓝边杯碟仍在原位，气泡落在杯沿，蓝边变为鲜亮但保留釉质感的花纹，杯子轻弹一下。第三镜：左侧靠窗椅背与其后的灰色墙面仍是旧貌，气泡滑落椅背，颜色沿椅背、墙角依次苏醒；桌位、窗框和空间结构不移动。每镜都先停留极短的“开罐前”状态，再让气泡入画并完成局部变化；三个触点之间用气泡运动方向衔接，最后切回主角手中的罐子。此时只改变被触到的局部，咖啡馆整体仍在变化途中。

接着气泡轻触主角腰间的灰棕格纹衬衫，黄棕色沿原有格纹向两侧蔓延。另一颗落在裤腿上，冷棕灰的布料顺着裤褶变成明亮的黄色；第三颗擦过上衣，宽松的灰米短袖收出更利落的短款轮廓，变为白色。**镜头清楚呈现同一人从开罐前造型到开罐后造型的过程**，卷发、耳环、鞋子和她手中的罐子都不变。主角低头看着变化，再抬眼，第一次露出笑意。随后一颗气泡擦过店员的衣袖，浅天蓝色沿上衣展开；另一颗落到围裙和裤腿，深棕围裙轻轻散成气泡，长裤变为明黄色宽松裤，鞋子变成浅色运动鞋。店员仍站在吧台后，愣了一瞬，又照常工作；客人杯中的咖啡轻轻颤了一下。

店员严肃地按住刚才轻弹的杯子，杯子又偷偷动了一下。店员继续倒咖啡，深棕色液流在半空轻轻扭出一道弧线，准确落入杯中。一颗气泡从杯沿弹到邻桌客人的灰色短外套上，珊瑚粉沿衣袖展开；她的深棕宽裤变为暖白色，脸和短黑发不变。客人放下杯子，终于也笑了。

邻桌那张反复掀角的 A5 纸此刻真正离开桌面，落到地上，自行折成一只暖白色纸鹤。一颗气泡触到它的翅膀，葡萄柚粉、青柠绿和一点亮黄沿折痕展开。纸鹤飞起，绕主角和饮料罐一圈，俯冲到吧台，叼走被她压在那里的小票。

主角握着**已开罐**的饮料，从吧台转向右前方，沿通向店门的右侧通道跟过去。气泡掠过椅背、门框与橱窗边缘，咖啡馆的材质和色彩逐处苏醒；桌椅、吧台与门的位置保持原样，空间没有突然变成另一家店。

**店内压缩节奏**：20–23 秒三个场景细节；23–27 秒主角变装；27–31 秒店员、杯子和客人的连续反应；31–35 秒纸张折鹤、叼走小票并引主角走向店门。保留已确认的动作因果，用短镜头接力，为马路上的行走和高楼变化留出 15 秒。

### 04｜目光所到之处，街道改变（35–50 秒）

纸鹤叼着小票从右前方玻璃门飞向街道。主角握着已开罐的饮料，走出同一扇门，踏下路沿，走进宽阔的马路。镜头从她侧后方跟上，再移到她前方倒退拍摄；她始终在向右前方走，店门和橱窗逐渐退到身后。几颗气泡从罐口上升、越过她的肩膀，沿她前进的方向一颗颗落下。**主角先看向某件仍是旧貌的真实物件，气泡随后落在她所看的地方，变化才开始**；目光引导画面，气泡负责触发变化。

她走过路沿，目光掠向左侧的黑色金属护栏。第一颗气泡落在立柱上，木纹从触点长出，横杆弯成占据原来位置的木栅栏。她没有停步，只回头看了一眼；镜头跟随她继续向前。

前方右侧原有的灰色汽车进入她视线。第二颗气泡落在车顶，亮黄与珊瑚粉从触点沿原车身扩散。车顶和车窗向后收拢，车身打开成有奶油白座椅的雪橇，车轮拉长、弯成两条滑橇；观众始终能认出它占据原车位置。气泡再掠过车头，短暂遮住接缝，一只写实驯鹿从彩色光雾中向前迈出，牵引杆与缰绳接上雪橇。它带着雪橇沿原车道向右前方前进；滑橇轻离湿路面，路上仍有清楚的影子与倒影，不突然出现雪景。主角边走边看，惊讶地笑了。

她的目光被前方高处的第三颗气泡带起。镜头越过她的肩膀向上仰拍：街道尽头那座开罐前就已出现的灰色玻璃高楼仍是冷调直线，气泡落在楼顶边缘。珊瑚粉和果黄沿立面向下蔓延，生硬的外墙转为有弧度的奶油色材质，青柠绿线条沿原窗格生长；**原楼的高度、层数、窗列和占地都可辨认**。这是店外最大的变化，不是凭空换成另一座楼。主角继续走在路中央，抬头看见整座高楼逐层苏醒。

下一颗较小的气泡落在她路过的黑色街灯上，灯杆弯出轻巧的弧线，灯罩变成透亮的果色灯球，灯柱底座仍固定在原位。镜头回到主角和街道同框：她走过的旧物依次留在身后，前方还有未变化的灰色街道。

开场那位骑车人从左向右经过，在她旁边稍远处停下；地上的影子却仍向前蹬了两下，才回头等他。骑车人追着影子骑走。主角一边继续向前，一边回头笑出声，手中的饮料罐仍清楚可见。她终于走出了重复的一秒。

**店外节奏参考**：35–37 秒出门、走入马路并建立跟拍；37–39 秒护栏变木栅栏；39–43.5 秒汽车逐步变雪橇、驯鹿出现并迈步；43.5–46.5 秒仰拍高楼逐层变化；46.5–47.5 秒街灯变形；47.5–49 秒骑车人与影子；49–50 秒主角继续行走与反应。每处都遵循“主角看见旧物 → 气泡落点 → 从触点变形 → 她继续向前”，避免站在店门口看完整条街瞬间换景。驯鹿与雪橇保留写实材质及产品色彩点缀，不追加雪景或节日布景。

### 05｜纸鹤归来（50–55 秒）

主角在已经变亮的马路上放慢脚步。纸鹤从上方折返，把小票轻轻放进她空着的手里。它又绕已开罐的饮料一圈，折成一顶保留相同粉、绿、黄花色的小纸帽，稳稳落在罐顶一侧，**不遮住罐身图案，也不盖住饮用口**。主角低头看着它，笑出声。

切产品定格：同一款水果气泡饮完整呈现，罐身图案清晰。纸帽可以在画面边缘作为故事记号；品牌名与广告语待定，预留后期排版空间。

## 叙事与制作锁定

1. **“卡在同一秒”要可见、可听**：杯子落桌、纸角掀起、骑车人经过、秒针回弹构成同一组重复事件。开罐声切断这组声音，秒针第一次向前走。
2. **产品位置连续**：饮料从开场就在吧台；主角走到吧台拿起、开罐，此后一直握在手中直至片尾。它不是突然出现的魔法物件。
3. **两张纸不能混淆**：邻桌的无印刷 A5 纸折成纸鹤；吧台上的窄条小票被纸鹤叼走、最后归还。片尾纸帽由同一只纸鹤折成。
4. **颜色有来源**：开罐后的变化沿用产品 v2 的亮黄、葡萄柚粉、青柠绿，亮蓝与橙色只作少量点缀。前段不让背景抢走饮料的第一视觉焦点。
5. **奇观逐级扩大**：主角服装变换 → 店员袖口与杯子 → 咖啡与纸鹤 → 咖啡馆苏醒 → 主角走上马路，护栏、汽车、高楼、街灯随她的目光依次变形。每次都由落下的气泡明确触发；旧物必须先被认出，再发生变化。高楼是街外的视觉高潮，骑车人与影子作短暂笑点收尾。
6. **两套服装状态锁定**：开罐前以新补的灰米冷棕全身图与三视图为准；开罐后以原有白上衣、黄裤、黄棕格纹的全身图与三视图为准。变装可拆成格纹、裤腿、上衣三个短镜头；每个镜头保留相同的人物姿势或衣物褶皱作为衔接。其他资产的现有状态见人物与道具清单。
7. **片尾文字暂不写死**：可在品牌确定后考虑“让这一秒，冒出新花样”等方向；本剧本不预设罐身品牌文字。
8. **空间方向已锁定**：座位在左侧靠窗，邻桌在其左后方，吧台在右后方，店门在右前方。主角从座位到吧台斜向右后方，从吧台到门沿右侧通道斜向右前方；出门后走入马路并持续向右前方，咖啡馆退到左后方。她依次看向路沿护栏、前方汽车、街道尽头高楼、路旁街灯。骑车人沿街向右运动，与她保持间距。
9. **店外变化连续**：木栅栏占用原金属护栏的位置；灰色汽车在开罐前街道中必须先出现，泡泡落车顶后先变开放式雪橇，再由车头前方出现驯鹿并接上牵引杆。完成体仍从原车位置沿同一车道向右前进，湿路面保留倒影，不凭空变雪地。灰色高楼和黑色街灯也须先在“沿马路前望”基准镜头出现，变化后保持占地、朝向与主要结构。骑车人和自行车不变形，影子沿原方向多骑两下。现有透明底驯鹿雪橇只锁造型，分镜需补匹配街道机位的三分之四后视角和中间变化帧。
10. **开罐后先看三处细节变化**：桌面、杯沿、靠窗椅背与墙角各使用同机位的变化前后画面，气泡必须明确落在接触点。三镜共约 3 秒，放在 20–23 秒；后续人物、纸鹤和出门仍按原节点推进。生成时分别以同一构图制作“未触碰”和“已触碰”状态，避免整间咖啡馆在一镜内突然换景。

## 分镜执行方式｜已确定

- 开场先用一个室内全景交代 A 布局：主角座位在左侧靠窗，邻桌在其左后方，吧台在右后方，店门在右前方。之后可以切人物、杯子、饮料和纸鹤的近景，也可以跟拍主角走动；这些镜头沿用同一套空间位置。
- 主角去吧台的运动方向为左前方向右后方；从吧台跟纸鹤出门为右后方向右前方，出门后走入马路并沿街持续前进。店外用跟拍主角、视线反打旧物、气泡落点与变形的镜头链维持行走感；反向拍人物表情时保留咖啡馆或高楼的空间标志，避免像在原地转圈。
- 分镜阶段按约 55 秒分配各镜头时长，优先保证开场重复、开罐瞬间、纸鹤引路和片尾回收的节奏。
