# 《世界卡在同一秒》｜水果气泡饮 TVC 剧本·修订版

> 基于 `story.md` 与 `references/新建文本文档.txt` 整合修改。此稿先锁定故事和动作因果，尚不是逐镜分镜表。

> 人物、产品、道具与场景统一采用中文标识；现有图片及待补项目见 [《人物与道具清单（55 秒版）》](./人物与道具清单-55秒版.md)。

## 故事定位

- **片长**：约 55 秒。
- **一句话故事**：困在重复一秒里的主角，打开一罐水果气泡饮，让颜色和意外从咖啡馆一路涌向街道，自己也第一次主动追了出去。
- **情绪线**：习惯重复 → 发现异常 → 主动选择 → 惊喜失控 → 享受当下。
- **视觉规则**：开罐前，现实空间以偏灰、米白、冷棕为主，同一秒的动作精确重演；饮料是画面里唯一鲜亮的颜色。开罐后，气泡触到哪里，哪里的颜色、动作或形态才发生改变。变化沿真实物体传播，保留真人摄影和实体道具的质感。
- **主角两套造型**：开罐前穿灰米色宽松短袖上衣、冷棕灰阔腿裤、灰棕格纹腰间衬衫；开罐后，气泡触碰服装并依次将其变为现有参考图中的白色短上衣、亮黄宽松裤、黄棕格纹腰间衬衫。这是画面中真实可见的服装变化，不只靠调色完成。人物面部、长卷发、大耳环和鞋子保持连续。

## 店内空间与行动路线｜已选 A：斜向推进

开罐前场景参考：[咖啡馆室内宽敞空间基准图 v2](./references/场景/咖啡馆室内-开罐前-宽敞空间基准-v2.png)。以加深加宽后的空间为准，锁定桌位、吧台、唯一的右前玻璃店门、橱窗与宽阔行动通道；旧版 v1 空间偏小，不再用于分镜。时钟及小票的具体位置在分镜阶段补定。

开罐后室内场景参考：[同机位蓝黄配色无泡泡底图 v3](./references/场景/咖啡馆室内-开罐后-无泡泡底图-v3.png)。墙面、吧台与椅子明显被唤醒，主色为天空蓝和奶油黄，珊瑚色只做少量点缀；地面仍以原有石材为主，前后桌位和行动通道不变。气泡使用[透明单颗素材](./references/道具/气泡-透明单颗-v1.png)或视频生成单独控制轨迹；[含静态泡泡的 v2](./references/场景/咖啡馆室内-开罐后-蓝黄配色-v2.png)仅作为氛围参考，不作视频底图。

店外场景参考：[咖啡馆外街角开罐前空间基准图 v1](./references/场景/咖啡馆外街角-开罐前-空间基准-v1.png)。外景延续同一排黑框橱窗与右侧玻璃门；门前的人行道供骑车人从左向右经过，主角出门后向右跑。

店外变化镜头沿用同一条人行道：门左侧靠路沿的黑色金属护栏变为木栅栏，保持原占地和间距；右侧道路预留一辆开罐前已出现的灰色汽车，用于变成马车。正式分镜前需在店外开罐前基准图里锁定汽车停放位置。骑车人与自行车保持原造型，留给后面的影子笑点。

**气泡视频规则**：开罐前画面无气泡；开罐后第一批从罐口向上升起，随后分成不同速度与大小的气泡，沿吧台上方、中央通道、窗边、店门依次运动。每颗气泡持续平移、轻微摆动和改变大小，触到物体时局部变色或形变，再弹开、破裂或飞出画面。不可让气泡在空间里原地悬停，也不可把含静态气泡的参考图直接当作视频底图。

以下方位以咖啡馆俯视平面为准：**上方是店内深处，下方是临街玻璃窗；画面左、右以从街上看向店内的建立镜头为准**。后续镜头可改变机位，但桌位、吧台、门的实际相对位置不变。

```text
                     店内深处
        ┌────────────────────────┐
        │ 邻桌／A5 纸      吧台／饮料 │
        │ 主角座位          右侧通道  │
        │                  店门      │
        └──────临街玻璃窗────────┘
                       街道
```

- **入场**：主角从右前方店门进入，沿桌椅前侧走向左侧靠窗座位，拉开椅子坐下；邻桌在她的左后方、靠店内深处。
- **走向产品**：主角从左侧座位起身，沿桌子与吧台之间的空通道，斜向右后方走到吧台。饮料固定摆在吧台朝向顾客的一侧，小票由店员推到饮料旁边。
- **出店**：主角拿着已开罐饮料，从吧台转向右前方，沿右侧通道追纸鹤回到同一扇店门；不横穿邻桌，也不在镜头间换一扇门。
- **纸鹤路线**：邻桌 A5 纸落地成鹤 → 绕主角与饮料一圈 → 飞向吧台叼走小票 → 沿右侧通道飞出门 → 街道上折返。小票是被带走并归还的另一件道具。
- **街外方向**：骑车人每次都沿橱窗外从左向右经过；他停下时，影子继续朝同一方向骑。主角从右前方的门跑出后沿街向右追纸鹤，避免与骑车人的运动方向无故对撞。

## 正式剧本

### 01｜同一秒，一直重来（0–12 秒）

清晨的街角咖啡馆。右前方的临街玻璃门被推开，主角穿着灰米短袖、冷棕灰阔腿裤和灰棕格纹腰间衬衫进入店内，走向左侧靠窗座位，拉开椅子坐下。邻桌在她的左后方，吧台在右后方。桌椅、咖啡机、杯碟都整齐得近乎刻板；整个空间是灰、米白与冷棕色。靠窗的客人端起咖啡，店员将一只米白色细蓝边杯子放上杯碟，窗外一位骑车人从左向右掠过。

“嗒”——杯子落桌。邻桌一张暖白色 A5 纸被风掀起一角。墙上秒针跳向下一格，却立刻回到原位。

主角学着客人端起咖啡。她刚要喝，**同样的一秒再次发生**：同一声“嗒”，同一张纸掀起同一个角，窗外同一辆车经过同一个位置。第三次，主角没有再举杯。她先看向杯子，再看向停在原处的秒针；她已经知道下一声“嗒”何时会响。

### 02｜唯一没有重复的颜色（12–20 秒）

主角听着下一声“嗒”将要响起，动作停了一下，视线自然地移向右后方吧台上的一罐水果气泡饮；她此时没有刻意微笑或惊讶。它始终在那里，只是之前被单调的节奏淹没；亮黄罐身与葡萄柚粉、青柠绿的果片图案，成为灰色画面中唯一鲜明的颜色。主角先一步站起，沿桌子之间的通道斜向右后方走到吧台。

她拿起饮料。店员把一张窄条小票推到罐子旁；主角顺手将小票压在吧台边，手指扣住拉环。客人仍照旧举杯。主角拉开罐口。

**“嘶——”** 清脆的开罐声盖过即将响起的“嗒”。秒针终于越过原来的刻度。店员与客人同时停下动作，看向主角手中的罐子。几颗带粉、绿、黄反光的透明气泡从罐口缓缓升起。

### 03｜变化从一颗气泡开始（20–39 秒）

第一颗气泡轻触主角腰间的灰棕格纹衬衫，黄棕色沿原有格纹向两侧蔓延。第二颗气泡落在裤腿上，冷棕灰的布料顺着裤褶变成明亮的黄色；第三颗擦过上衣，宽松的灰米短袖收出更利落的短款轮廓，变为白色。**镜头清楚呈现同一人从开罐前造型到开罐后造型的过程**，卷发、耳环、鞋子和她手中的罐子都不变。主角低头看着变化，再抬眼，第一次露出笑意。随后一颗气泡擦过店员的衣袖，浅天蓝色沿上衣展开；另一颗落到围裙和裤腿，深棕围裙轻轻散成气泡，长裤变为明黄色宽松裤，鞋子变成浅色运动鞋。店员仍站在吧台后，愣了一瞬，又照常工作；客人杯中的咖啡轻轻颤了一下。

气泡碰到杯碟，杯子像忍不住似的弹跳两下。店员严肃地按住杯子，杯子又偷偷动了一下。店员继续倒咖啡，深棕色液流在半空轻轻扭出一道弧线，准确落入杯中；杯口的蓝色细边随之变成一圈鲜亮但仍像釉彩的花纹。一颗气泡从杯沿弹到邻桌客人的灰色短外套上，珊瑚粉沿衣袖展开；她的深棕宽裤变为暖白色，脸和短黑发不变。客人放下杯子，终于也笑了。

邻桌那张反复掀角的 A5 纸此刻真正离开桌面，落到地上，自行折成一只暖白色纸鹤。一颗气泡触到它的翅膀，葡萄柚粉、青柠绿和一点亮黄沿折痕展开。纸鹤飞起，绕主角和饮料罐一圈，俯冲到吧台，叼走被她压在那里的小票。

主角握着**已开罐**的饮料，从吧台转向右前方，沿通向店门的右侧通道追过去。气泡掠过椅背、门框与橱窗边缘，咖啡馆的材质和色彩逐处苏醒；桌椅、吧台与门的位置保持原样，空间没有突然变成另一家店。

### 04｜这一秒，跑向街道（39–50 秒）

纸鹤叼着小票穿过右前方自动敞开的玻璃门。主角握着已开罐的饮料，跟着它从同一扇门冲出咖啡馆，沿街向右跑；气泡先于她掠过人行道。

一颗气泡碰到门左侧的黑色金属护栏。立柱从触点长出木纹，横杆顺势弯成真正的木栅栏；栅栏仍站在原来的路沿位置，不封住主角的去路。前方水洼里，先映出一辆马车的轮廓。镜头抬起，右侧道路上那辆原本灰扑扑的汽车被下一颗气泡触到：轮毂舒展成木辐条，车身折起成车厢，一匹马踏出一步，拉着马车缓缓向右。车窗里原本低头的乘客抬头，白胡子与红帽子在一瞬间出现——成了圣诞老人。他还握着手机，自己也愣住了。街角的色彩随变化扩散，但咖啡馆的门窗和街道走向仍清晰可认。

开场那位骑车人再次从左向右经过。他抬头看见气泡飞过，在木栅栏旁停下车；地上的影子却仍向前蹬了两下，才回头等他。骑车人愣了一瞬，随即追着自己的影子骑走。主角看见这一幕，笑着继续向右跑。她不再追赶重复的那一秒，而是在追眼前不断发生的新事。

**店外节奏参考**：39–40 秒出门；40–42 秒护栏变木栅栏；42–45 秒水洼预告与汽车变马车；45–46 秒车内乘客变身、抬头；46–49 秒骑车人与影子；49–50 秒回到主角。圣诞老人只作一眼可认的荒诞笑点，不追加雪景或节日布景。

### 05｜纸鹤归来（50–55 秒）

纸鹤从上方折返，把小票轻轻放进主角空着的手里。它又绕已开罐的饮料一圈，折成一顶保留相同粉、绿、黄花色的小纸帽，稳稳落在罐顶一侧，**不遮住罐身图案，也不盖住饮用口**。主角低头看着它，笑出声。

切产品定格：同一款水果气泡饮完整呈现，罐身图案清晰。纸帽可以在画面边缘作为故事记号；品牌名与广告语待定，预留后期排版空间。

## 叙事与制作锁定

1. **“卡在同一秒”要可见、可听**：杯子落桌、纸角掀起、骑车人经过、秒针回弹构成同一组重复事件。开罐声切断这组声音，秒针第一次向前走。
2. **产品位置连续**：饮料从开场就在吧台；主角走到吧台拿起、开罐，此后一直握在手中直至片尾。它不是突然出现的魔法物件。
3. **两张纸不能混淆**：邻桌的无印刷 A5 纸折成纸鹤；吧台上的窄条小票被纸鹤叼走、最后归还。片尾纸帽由同一只纸鹤折成。
4. **颜色有来源**：开罐后的变化沿用产品 v2 的亮黄、葡萄柚粉、青柠绿，亮蓝与橙色只作少量点缀。前段不让背景抢走饮料的第一视觉焦点。
5. **奇观逐级扩大**：主角服装变换 → 店员袖口与杯子 → 咖啡与纸鹤 → 咖啡馆苏醒 → 店外护栏变木栅栏、汽车变马车。每次变化都由气泡触碰触发；水洼倒影只预告马车，不单独变出第二辆车。店外以这两次实体变化为主，避免用更多零碎装饰挤掉骑车人与影子的笑点。
6. **两套服装状态锁定**：开罐前以新补的灰米冷棕全身图与三视图为准；开罐后以原有白上衣、黄裤、黄棕格纹的全身图与三视图为准。变装可拆成格纹、裤腿、上衣三个短镜头；每个镜头保留相同的人物姿势或衣物褶皱作为衔接。其他资产的现有状态见人物与道具清单。
7. **片尾文字暂不写死**：可在品牌确定后考虑“让这一秒，冒出新花样”等方向；本剧本不预设罐身品牌文字。
8. **空间方向已锁定**：座位在左侧靠窗，邻桌在其左后方，吧台在右后方，店门在右前方。主角从座位到吧台斜向右后方，从吧台到门沿右侧通道斜向右前方；街外骑车人与追纸鹤的主角均向右运动。
9. **店外变化连续**：木栅栏占用原金属护栏的位置；灰色汽车在开罐前外景中必须先出现，变成马车后仍位于同一车道并向右前进。骑车人和自行车不变形，影子沿原方向多骑两下。圣诞老人是车内原乘客的短暂变身，手机留在手里，避免误认成新人物突然上车。

## 分镜执行方式｜已确定

- 开场先用一个室内全景交代 A 布局：主角座位在左侧靠窗，邻桌在其左后方，吧台在右后方，店门在右前方。之后可以切人物、杯子、饮料和纸鹤的近景，也可以跟拍主角走动；这些镜头沿用同一套空间位置。
- 主角去吧台的运动方向为左前方向右后方；从吧台追纸鹤出门为右后方向右前方。需要反向拍人物表情时，用前一个走位镜头或清楚的空间标志衔接，避免看起来像换了座位或店门。
- 分镜阶段按约 55 秒分配各镜头时长，优先保证开场重复、开罐瞬间、纸鹤引路和片尾回收的节奏。
