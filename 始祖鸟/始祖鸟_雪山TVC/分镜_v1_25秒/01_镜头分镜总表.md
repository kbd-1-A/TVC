# 始祖鸟青蓝色冲锋衣·雪山 TVC｜25 秒镜头分镜 v1

**画幅**：16:9。**时长**：25 秒（用户给定范围 20–30 秒）。**故事线**：冰爪与手确认攀登 → 人物继续向上 → 停下拉起冲锋衣 → 拉链线切为山脊线 → 人物融入雪山。

这一版是镜头分镜，`关键帧/` 中每个 `SH###` 是对应镜头的干净首帧或关键动作帧；静帧并不代表连续动作视频已完成。

## 连续性锁定

- **空间**：同一座雪山，三峰始终位于画面右上，云海在左；坡面上升方向是画面左下 → 右上。空镜、近景和终景都继承这一方位。
- **人物**：同一位深棕色侧分中长发女性，青蓝色冲锋衣、黑色内搭/裤/手套、黑灰小背包、双脚冰爪、银灰直柄冰镐。近景可不让冰镐入画，但装备造型不变。
- **风与光**：冷灰阴天漫射光；风将发丝吹向画面左侧。不可突然变晴、换成另一座山或反向行进。
- **主转场**：拉链从下往上，滑块到领口时画面中心的拉链线，切成从近处往远处上行的雪山脊线。剪辑点在滑块触及领口的“咔哒”声上。
- **声音**：冰爪压雪、手套擦岩、呼吸、风、拉链声。音乐与品牌字卡暂留后期决定。

## 剪辑重点

1. **0–6 秒保留原定开场**：冰爪、抓岩、拉到攀登远景。两个动作近景各约 1.5 秒，远景 3 秒。
2. **SH006–007 是同一个连续动作**：滑块从腰部到胸口，再到领口；视频生成时不得在切镜处倒退或突然闭合。
3. **SH007 → SH008 不做融化特效**：在滑块到顶那一帧做线条匹配硬切，靠拉链声音与同向运镜完成转场。
4. **SH009 → SH010 同一条脊线**：以岩石前景或云雾遮挡作剪辑点，不让小人物突然在同一个静止机位中凭空出现。
5. 每镜单独生成一个视频片段，镜头内部只安排一个主要动作和一种主要运镜；生成时为头尾各留约 0.5 秒可剪余量。

关键帧已覆盖 10 个镜号。视频制作前优先核对：人物脸部一致性；银灰冰镐的长度与握法；冰爪前齿与雪面的接触；拉链从开到闭的连续状态；三峰在各镜中的方位。
