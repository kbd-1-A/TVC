# 雪山 TVC｜23 秒分镜 v4（当前版）

保留 v3 的攀登、人物和一次拉衣领动作。原 SH007 的三张相似脊线近景与 3 秒停留，改为**一张横幅脊线画面、1 秒**；随即切山体远景。片长因此从 25 秒缩为 23 秒，仍在约 20–30 秒的目标范围。

SH006→SH007 靠领口处的拉链声与向上延伸的线条接镜。脊线是一个短暂的转场画面，不再假装三张相近照片能构成持续前移。SH007 用 16:9 素材，预览画面无竖幅两侧黑边。

预览有 23 秒、24 fps、552 个播放帧，但其中只有 25 张不同的静态关键画面；真正连续的衣服、头发与镜头运动仍需后续视频制作。此项目是始祖鸟风格概念练习，服装图不是经过核验的官方产品素材。
