## 接镜检查

**SH005 → SH006**：视线都向下，人物都是右向近侧脸，发丝向画面左侧吹。SH005 中主拉链已经在胸口附近，所以 SH006 从胸口继续上拉；拉头不能退回腹部。两镜之间允许手进入画面，不需要人物先抬头再低头。

**SH006 → SH007**：在滑块触到领口的声音处硬切；雪岩脊线接衣服的上行线条。人物不必做完成动作的表情或再次望山。

**产品呈现**：冲锋衣始终是攀登者穿在身上的功能装备。新版只用约 1.5 秒交代拉合动作，镜头保持脸、风和山景的关系；避免连续正面特写让人物像在演示产品。

这些图是静态动作节点。预览是 25 秒、24 fps 的定时静帧片，共 600 个播放帧，但只有 27 张不同的关键画面；真正的连贯运动仍需在视频生成／剪辑阶段制作。

这是始祖鸟风格概念练习，服装图不是经过核验的官方产品素材。
